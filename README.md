This is a number guessing game. The computer picks a random number between 1 and 100. And you must guess the right number.
The program tells the user if their guess is too high or too low and keeps track of their attempts.

How to Run
Open Main.java.
Run the program.
Enter a number between 1 and 100.
Keep guessing until you get the correct number.
